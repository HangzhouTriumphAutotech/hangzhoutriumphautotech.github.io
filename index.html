为什么选择 TradeInWork

三个共同的产品主张

无论 TradeWork 还是 TradeCoWork，我们都坚持这三件事。

数据自主

数据存在你的电脑或你的内网，从不上云

TradeWork 使用本机 SQLite，TradeCoWork 使用内网 MySQL。 所有客户名单、订单金额、合同信息均不经过任何第三方云服务， 适合对商业机密有合规要求的外贸团队。

  • 一键备份与恢复，自托管
  • 完整操作日志审计
  • 员工数据按权限隔离（含仅看本人数据）
  • TradeWork 数据库本机 SQLite
  • TradeCoWork 数据库内网 MySQL
  • 云端依赖无强制上云
  • AI 对话可选 API，会话本地落库
AI 赋能

内置 AI 助手，懂你的业务数据

通过 DAP（Data Access Protocol）让 AI 在授权范围内查询业务数据； 管理员配置模型与 API Key，员工使用斜杠命令调用 Skill， 提升写邮件、看报表的效率。

  • 订单统计解读、客户分析、报表摘要
  • 外贸邮件草稿（询价/报价/催款等场景）
  • 流式 Markdown 回复，会话按员工隔离
  • /analyze-orders订单分析
  • /analyze-customers客户洞察
  • /draft-email邮件撰写
  • DeepSeekOpenAI 兼容接口

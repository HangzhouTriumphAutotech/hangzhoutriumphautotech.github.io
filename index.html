数据安全

纯本地部署，业务数据不出电脑

基于 Electron + SQLite 架构，数据库与附件保存在用户目录，支持 ZIP 备份与恢复。适合对商业机密、客户名单有严格合规要求的企业。

  • 一键数据导入导出与自动备份
  • 完整操作日志审计
  • 员工数据按权限隔离（含仅看本人数据）
  • 数据库本机 SQLite
  • 附件存储本地 uploads
  • 云端依赖无强制上云
  • AI 对话可选 API，会话本地落库
AI 赋能

内置 AI 助手，懂您的 CRM 数据

通过 DAP（Data Access Protocol）让 AI 在授权范围内查询业务数据；管理员配置模型与 API Key，员工使用斜杠命令调用 Skill，提升写邮件、看报表的效率。

  • 订单统计解读、客户分析、报表摘要
  • 外贸邮件草稿（询价/报价/催款等场景）
  • 流式 Markdown 回复，会话按员工隔离
  • /analyze-orders订单分析
  • /analyze-customers客户洞察
  • /draft-email邮件撰写
  • DeepSeekOpenAI 兼容接口

TradeWork

典型外贸业务闭环

在 TradeWork 中，常见流程可在一个系统内完成，减少 Excel 与邮件来回切换。

  1. ① 获客与跟进

    录入客户与联系人，记录电话/邮件/拜访跟进，标记等级与下次跟进时间。

  2. ② 报价与合同

    出具客户报价单，确认后生成销售合同与 PI；采购侧同步 PO 与采购合同。

  3. ③ 订单执行

    销售订单驱动生产发货状态；关联采购订单与物流订单及费用。

  4. ④ 对账与分析

    报表查看销售额、成本、利润率；AI 助手辅助解读趋势与撰写跟进邮件。

  5. ⑤ 系统运维

    员工与字典维护、操作日志、定期 ZIP 备份，保障业务连续性。

  6. ⑥ 效率扩展

    应用市场打开汇率/翻译等工具；全局搜索快速定位客户与订单。
